# LR-0001: самооценка опыта выше подтверждённого уровня

Ученик указал опыт с Node/Nest, React+TS и Postgres, но диагностика (2026-10-14, 20 вопросов) подтвердила в основном узнавание терминов (N+1, EXPLAIN ANALYZE, micro/macrotask) без механики. TS generics, Nest DI/lifecycle, модель рендеринга React, TanStack Query, RTL, compose — на уровне none.

Evidence: `.teachify/diagnostic-results.md` (q1–q20), сводка в PROFILE.md.
Implications: учить с фундамента (TS-типы → React-модель / Nest-модули), не пропускать «базовые» уроки; цель L2 за 3–4 месяца нереалистична без пересмотра срока или объёма.
